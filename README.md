# Punam Gaikwad — Portfolio

## Files
- `index.html` — portfolio content and page structure
- `portfoliocss.css` — responsive styling
- `script.js` — mobile navigation and automatic footer year

## Run locally
Open `index.html` in a browser. An internet connection is needed for Google Fonts and Bootstrap Icons.

## Publish on GitHub Pages
1. Copy all three files into the root of your portfolio repository (the same folder as the existing `index.html`).
2. Commit and push the changes.
3. In GitHub, open **Settings → Pages** and confirm the correct branch and root folder are selected.
4. Wait for GitHub Pages to deploy, then refresh your portfolio URL.

## Before publishing
- Add a current PDF resume to the repository if you want a dedicated download button. I have not added a fake resume link.
- The contact form uses FormSubmit to deliver messages to `gaikwadpunam2000@gmail.com`. On the first test submission, FormSubmit sends a verification email to that inbox. Open it and confirm the activation link; after activation, contact-form submissions will be delivered there. Check Spam/Junk if the verification email is not in the inbox. FormSubmit is a third-party service.
- Confirm that the project descriptions and dates match what you are comfortable sharing publicly.
- The project descriptions are summaries; add screenshots only if you have permission to share them.
